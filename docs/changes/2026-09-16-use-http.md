# Plain JSON requests with useHttp

Add an exported useHttp helper with the field/reset/error interface of the
existing useForm helper and Inertia core's HTTP client and argument parsing.
Requests return parsed JSON without an Inertia visit. State changes call Imba
commit, so loading, validation and response UI update automatically.

Supported: HTTP verbs, prebound endpoints, transforms, query serialization,
JSON/multipart bodies, upload progress, response state, callbacks, cancellation,
and first/all validation errors. HTTP 422 resolves undefined after updating
errors; other failures reject. One pending request per instance is enforced to
prevent stale responses from corrupting state. Use separate instances for
independent work, and cancel on unmount when appropriate.

Rails meta CSRF headers are forwarded only to the current origin. Explicit
headers override defaults case-insensitively. The new fixture JSON greeting
endpoint validates without persisting data and retains Rails CSRF protection.
The About page demonstrates validation and successful JSON requests; its styles
remain in frontend/styles/style.imba.

Verification:
- npm test: 22 tests passed. HTTP coverage includes JSON/query/multipart transport,
  upload progress, 422 and retry, callback/transform failure cleanup, cancellation,
  concurrent request protection, empty/malformed responses, success timers,
  defaults and same-origin CSRF handling.
- Rails tests: 11 tests, 55 assertions, zero failures, including missing-token
  rejection, JSON success, validation, and no database writes.
- Production frontend build passed.
- Browser with Rails and Vite: blank preview rendered validation, retry with Ada
  rendered Hello, Ada!, button was re-enabled, URL stayed /about, and layout
  counter stayed at 1. No valid database records were created.

Limits: isDirty, remembered state, optimistic updates, Precognition and nested
field-path helpers are not implemented. The existing useForm helper's cloning
and top-level reset/default conventions are retained. No claim of full Svelte
adapter parity; README documents the supported subset.
